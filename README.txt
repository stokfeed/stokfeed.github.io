STOKFEED v19 — GitHub GUI static site

Upload the CONTENTS of this folder to your GitHub repository root using Add file > Upload files. No GitHub workflows, npm, Python publisher or build button. GitHub Pages must serve main/(root).

Requires deploying the matched zeos.js Worker from the sibling worker folder. Existing STORIES KV, secrets and three Cron triggers remain unchanged. The stock research tool uses publicly available SEC companyfacts and a dated vendor snapshot. Missing data is reported as missing and not invented.

Files include stock.html, research.js, loader.js, dropdown navigation and logo-loader animation.

Do not upload README/test resources to the website if you do not want them public.

Stock reports additionally use supported provider-sourced 1-/3-/5-year total returns, volatility, beta, drawdown, highs/lows and P/E when available.
